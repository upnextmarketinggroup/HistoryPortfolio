# Research Portfolio — HISTC1002

A plain HTML/CSS static site built for a Fall 2026 HISTC1002 assignment. No build
tools or frameworks — it can be hosted directly on GitHub Pages.

## Project structure

- `index.html` — home page
- `about.html` — About Me page
- `styles.css` — shared styles
- `images/` — folder for photos (see below)
- `README.md` — this file

## Turning on GitHub Pages

1. Push this repository to GitHub (already done if you're reading this on GitHub).
2. On GitHub, open the repository and click **Settings**.
3. In the left sidebar, click **Pages**.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
5. Under **Branch**, choose **main** and folder **/ (root)**, then click **Save**.
6. Wait a minute or two for GitHub to build the site. Refresh the **Pages**
   settings page — the live link will appear near the top of that page once
   it's ready (something like `https://<username>.github.io/<repo-name>/`).
